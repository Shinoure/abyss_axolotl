# ABYSS — Axolotl Club (desktop prototype)

## Запуск для разработки
Требуется Node.js 20+.

```bash
npm install
npm start
```
Открой http://localhost:3000

## Запуск desktop-версии
```bash
npm install
npm run desktop
```

## Сборка Windows EXE
```bash
npm install
npm run dist:win
```
Установщик появится в `dist/`.

Можно также загрузить проект в GitHub и запустить workflow **Build Windows EXE** через Actions. Готовый `.exe` будет доступен как Artifact.

## Важное про игру с друзьями
Сейчас Electron-приложение запускает локальный игровой сервер на компьютере игрока. Это подходит для соло и тестирования на одном ПК. Чтобы друзья из разных сетей подключались друг к другу, нужен постоянно доступный публичный сервер. Один только `.exe` не создаёт интернет-соединение между компьютерами. Следующий этап — вынести Socket.IO сервер на хостинг и добавить в клиент адрес сервера/систему подключения.
